# HTB Writeups (Public)

A public portfolio of sanitised Hack The Box writeups and methodology notes.

**Publication policy:** Any machine-specific walkthrough content is published only after the machine has retired. This repository does not contain spoilers for active machines. The Connected entry is currently a non-spoiler stub: its retirement status has not been independently verified, so no machine-specific solution details are included.

## Methodology

- **Recon:** Confirm the target is retired and define the permitted scope; map the exposed attack surface.
- **Enumeration:** Systematically investigate discovered services and record evidence, avoiding assumptions.
- **Foothold:** Document only a verified path to initial access, with sensitive artifacts removed.
- **Privilege escalation:** Explain the verified escalation path and relevant reasoning, without publishing secrets.
- **Reporting:** Summarise impact and practical remediation, then review the writeup against the sanitisation checklist before publication.

This describes a general workflow only; it does not disclose details of active machines.
